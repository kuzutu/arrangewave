# ArrangeWave

Start with a genre. Finish with a song. ArrangeWave turns a genre idea into a full Ableton Live 12 arrangement: song form, melody, chords, bass and sub from one shared harmony, instruments, sidechain and automation. Free for macOS and Windows, works offline.

**Download:** [download page](https://kuzutu.github.io/arrangewave/) or the [latest release](https://github.com/kuzutu/arrangewave/releases/latest).

| File | For |
|---|---|
| `ArrangeWave_V58_macOS.dmg` | macOS 12 or later, Apple Silicon and Intel |
| `ArrangeWave_V58_Windows_x64_Setup.exe` | Windows 10/11 (64-bit), installer |

Requires Ableton Live 12 to play the generated projects. The app is not signed by Apple or Microsoft; the first launch needs one extra click. Steps are on the download page.
